# UK English

Public website and admin copy use UK English. The source text audit found no occurrences of the checked US variants, including organization/organize, center, program, neighbor, behavior, favorite, optimize, canceled, traveling, catalog and gray. CSS properties and third-party identifiers keep their required technical names.

The HTML language is explicitly en-GB. Donations use GBP and en-GB number formatting; public dates use en-GB formatting, with Europe/London in the shared full-date formatter. Terms already used include organisation, programmes, enquiries, optimised, travelling and cancelled. Future text entered in the CMS should follow the same style.
